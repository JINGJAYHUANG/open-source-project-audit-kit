# Roadmap

## 0.1.x

- collect external feedback on criterion ambiguity and false confidence;
- add Windows and macOS collector jobs;
- add SPDX-expression parsing without weakening the no-runtime-dependency default;
- add signed release provenance where supported.

## 0.2.0

- optional, read-only GitHub snapshot importer with explicit rate-limit and freshness metadata;
- time-series comparison report with materiality thresholds;
- pluggable organization-specific profiles;
- SARIF output for structural repository findings.

No roadmap item authorizes private-repository access, automatic credential discovery, or unattended production adoption.
