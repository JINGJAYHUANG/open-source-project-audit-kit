# Security policy

Please report suspected vulnerabilities through GitHub's private vulnerability reporting mechanism when available. Do not include real tokens, private repository content, personal data, or proprietary audit evidence in a public issue.

The local collector does not execute target-project code and does not make network requests. It may read text files and local Git metadata inside the selected checkout. Run it against a disposable copy when the repository itself is untrusted.

This toolkit is not a substitute for legal review, code review, dependency scanning, sandbox testing, or a professional security assessment.
