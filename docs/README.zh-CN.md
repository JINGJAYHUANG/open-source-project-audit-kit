# 开源项目审计工具包

本项目用于回答：一个开源仓库是否值得**采用、试点、观察或避免**，以及一个新项目是否值得进一步调查。

它不会把所有判断压缩成一个看似精确的数字，而是分开报告：

- 保守总分；
- 已观察部分的质量；
- 加权证据覆盖率；
- 证据可信度与独立性；
- License、安全、权限、可逆安装和场景适配等硬门槛。

任何非空评分都必须附带带日期的证据。未知项不会从分母中消失，因此少量漂亮材料不能制造虚高分。Stars、Forks、下载量和营销措辞只能作为有限信号，不能自动证明真实采用、安全性或长期维护。

本仓库只包含公开方法、代码和虚构案例，不包含私有仓库内容、个人资料、Token、客户数据或真实商业机密。离线采集器只检查本地文件和 Git 元数据，不联网，也不声称完成代码级安全审计。
