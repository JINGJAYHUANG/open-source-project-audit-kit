## Open Source Project Audit Kit v0.1.0

Evidence-first open-source due diligence with separate score, coverage, confidence, and hard-gate semantics.

### Included

- `adoption-readiness` and `innovation-scouting` profiles;
- evidence-required ratings and dated gate decisions;
- a deterministic no-network local collector;
- JSON, Markdown, HTML, spreadsheet-safe CSV, and comparison outputs;
- three synthetic adoption examples plus one innovation-scouting example;
- Python 3.11–3.13 CI and a reproducible-wheel gate.

### Boundary

This release is not legal advice, a security certification, or a guarantee of maintainability, adoption, or production fit. It includes no private-repository access, credentials, or personal profile data.
