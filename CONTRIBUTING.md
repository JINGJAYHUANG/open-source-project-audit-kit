# Contributing

Changes to criteria, weights, thresholds, gates, or recommendation language are methodology changes and require:

- a clear decision rationale;
- updated documentation;
- positive and negative fixtures;
- strict rubric validation;
- no weakening of the evidence requirement;
- no private repository content or unsupported grades.

Run:

```bash
PYTHONPATH=src python tools/release_check.py
```

Use synthetic or clearly licensed public fixtures. Never submit credentials or copied proprietary reports.
